# 📊 Data Cleaning & Exploratory Data Analysis (EDA)

A complete Data Cleaning and Exploratory Data Analysis (EDA) project using **Python, Pandas, NumPy, Matplotlib, and Seaborn**. This project focuses on transforming raw data into meaningful insights by cleaning, preprocessing, and visualizing the dataset.

---

## 📌 Project Overview

In this project, I performed:

- ✅ Data Cleaning
- ✅ Handling Missing Values
- ✅ Removing Duplicate Records
- ✅ Data Type Conversion
- ✅ Feature Engineering
- ✅ Outlier Detection
- ✅ Exploratory Data Analysis (EDA)
- ✅ Data Visualization
- ✅ Finding Business Insights

## 📊 Data Cleaning Process

The following preprocessing steps were performed:

- Removed duplicate records
- Checked null values
- Filled/Dropped missing data
- Converted incorrect data types
- Renamed columns
- Removed unwanted columns
- Fixed inconsistent values
- Checked unique values
- Detected and handled outliers
